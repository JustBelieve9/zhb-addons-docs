# zhb addons — documentation

Публичная документация набора Blender-аддонов zhb для Blender 5.2 LTS.

- Онлайн-руководство: https://justbelieve9.github.io/zhb-addons-docs/
- `ZHB_HANDBOOK.md` — та же документация в Markdown.

Справочник интерфейса генерируется из зарегистрированных панелей, операторов и
свойств исходных аддонов; приватный исходный код в этот репозиторий не входит.

Актуальная версия: **ZHB Bundle 2026.10.12**, восемь пакетов.
[Релиз и установщики](https://github.com/JustBelieve9/zhb_core/releases/tag/bundle-v2026.10.12)
находятся в приватном репозитории; для скачивания требуется доступ.

Сайт публикуется из `main:/`. `index.html` и `ZHB_HANDBOOK.md` берутся из
`zhb_core/docs/`, собранных штатным `tools/build_handbook.sh`; текущая проверка
полноты покрывает 136/136 операторов.
